# 明卷查經

獨立新站（不是覆蓋舊專案）。資料來自[華人基督徒查經資料網站](https://www.ccbiblestudy.org/index-T.htm)，只重排版面以便手機閱讀。

## 這版有什麼

- 六十六卷經文註解／拾穗／例證／信息／綱目
- 以賽亞、耶利米、以西結等卷已對準原站檔名，不再整章空白
- 主題長文已去掉 Word 殘留欄位（如 `{Section:TopicID=…}`）
- 人物欄：按書卷與章節列出主要人物，點進去讀該章（不含 AI 繪圖）

## 本機預覽

```bash
npm install
npm run dev
```

瀏覽器打開終端提示的位址即可。
