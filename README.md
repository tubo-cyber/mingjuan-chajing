# 明卷查經

手機也能順讀的查經讀本。經文註解、拾穗、例證、信息、綱目與主題專輯，資料來自[華人基督徒查經資料網站](https://www.ccbiblestudy.org/index-T.htm)。本站只重排版面與閱讀體驗，不改寫原文。

## 能做什麼

- 舊約、新約六十六卷，按章閱讀
- 同一章可切換：註解、拾穗、例證、信息、綱目、譯文
- 主題專輯、作者專欄
- 字體、字級、行距、紙色（素紙 / 夜讀 / 青暮）、繁簡

收藏與閱讀紀錄存在這台裝置上。
